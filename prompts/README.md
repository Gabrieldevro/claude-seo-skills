# SEO prompt library

Copy-paste prompts for **Claude** (claude.ai, the desktop app, or the API) — they also work in other assistants. Replace the `{{placeholders}}`. Prompts are written so the model asks for missing facts instead of inventing them.

**Tips**
- Give context: paste the page HTML or text, your country/language, and your audience. Claude can't guess your prices or USPs.
- Ask for tables when comparing options; ask for "exact code to paste" when you want implementation.
- Check facts before publishing. A prompt is a starting point, not a substitute for knowing your business.
